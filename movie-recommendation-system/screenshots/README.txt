To generate one:
1. Run `streamlit run app.py`
2. Open the app in your browser (usually http://localhost:8501)
3. Select a movie and click "Get Recommendations"
4. Take a screenshot and save it in this folder
5. Reference it in the README, e.g.: ![App Screenshot](screenshots/app_screenshot.png)
